# 水面行走坐骑（水黾类）制作流程

本手册面向维护人员与 Agent，描述在 AzerothCore 3.3.5a 上把坐骑做成「水面行走」（水黾类）的完整流程、字段填写与注意事项。

> **定位**：纯客户端 DBC 改动，无需服务端 SQL 与核心补丁。所有数值均核对自本地 `data/wow-dbc/src/dbc/`、AzerothCore 源码（`/Users/deadwalk/Code/azerothcore-wotlk/`）与本机 `acore_world` 数据库，非臆测。

---

## 1. 原理

- 水面行走 = 坐骑光环上多挂一个 `SPELL_AURA_WATER_WALK = 104`（`SpellAuraDefines.h` L167）。
- 处理器 `AuraEffect::HandleAuraWaterWalk` → `target->SetWaterWalking(true)`，对玩家有效（`SpellAuraEffects.cpp` L3448）。
- 官方参照法术 `546`（萨满 Water Walking）本地 `Spell.dbc` 实测：`Effect_1=6`（APPLY_AURA）、`ImplicitTargetA_1=1`、`EffectAura_1=104`、`EffectBasePoints_1=-1`。
- 效果挂在坐骑光环上，**随上马生效、下马消失，受击不会消失**（坐骑光环 `AuraInterruptFlags=0`，实测 61425）。

---

## 2. 前置条件

1. 坐骑法术已存在且为标准双效果结构：`Effect=[6,6,0]`、`Aura=[78,32,0]`（第三效果位空闲）。本项目坐骑法术均为此结构。
2. 词表候选坐骑：0455/0456 水黾（`special_features=水面行走`）。

---

## 3. 制作步骤：坐骑法术加第三效果

只改 `Spell.dbc` 该坐骑法术记录的第三效果组：

| 字段 | 值 | 说明 |
|------|-----|------|
| `Effect_3` | `6` | SPELL_EFFECT_APPLY_AURA |
| `ImplicitTargetA_3` | `1` | TARGET_UNIT_CASTER（骑乘者本人） |
| `EffectAura_3` | `104` | SPELL_AURA_WATER_WALK |
| `EffectBasePoints_3` | `-1`（0xFFFFFFFF） | 该光环无数值，沿用官方 546 写法 |
| `EffectMiscValue_3` | `0` | 无需 |

其余字段（`EffectDieSides_3`、`EffectRadiusIndex_3` 等）保持 `0`。

---

## 4. 注意事项

1. **不要**把水面行走做成独立 buff 法术触发——直接挂在坐骑法术上，机制最简单且随下马自动清理。
2. 水面上骑行时从水面向高处岸边的过渡由客户端自动处理，无需额外字段。
3. 该光环有反作弊配合（`AnticheatSetUnderACKmount`），属正常路径，不会误报。
4. 与「水面站立时是否会摔伤」无关：水行状态落到水面按落在水上处理。

---

## 5. 本项目落地差距

| 差距 | 现状 | 建议 |
|------|------|------|
| 导出管线不支持第三效果 | `patch_exporter.py` 坐骑法术模板只写 `Effect_1/2`（L43–56） | YAML `special_features` 含 `水面行走` 时，生成的 Spell.dbc 记录追加第三效果（6/1/104/-1） |
| 无前人验证 | 本项目首个水黾坐骑 | 首只上线后实测水面骑乘 |
