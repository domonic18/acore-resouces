# 自带商人 / 修理坐骑（牦牛、苔原猛犸象类）制作流程

本手册面向维护人员与 Agent，描述在 AzerothCore 3.3.5a 上把坐骑做成「自带商人 / 修理」（雄壮远足牦牛、旅行者的苔原猛犸象类）的完整流程、字段填写与注意事项。

> **定位**：商人/修理 = 载具挂件机制 + 商贩 NPC。载具部分复用多人骑乘文档，本文只写商贩特有内容。所有数值均核对自本地 `data/wow-dbc/src/dbc/`、AzerothCore 源码（`/Users/deadwalk/Code/azerothcore-wotlk/`）与本机 `acore_world` 数据库，非臆测。

---

## 1. 原理

1. 商贩 NPC 通过 `vehicle_template_accessory` 挂在坐骑载具的乘客座位上（机制详见 [`02多人骑乘坐骑制作流程.md`](./02多人骑乘坐骑制作流程.md) §4.5）。
2. 商贩能力由 NPC 的 `npcflag` 决定（`UnitDefines.h` L329–334）：

| 旗标 | 值 | 含义 |
|------|-----|------|
| `UNIT_NPC_FLAG_VENDOR` | `0x00000080` | 通用商人 |
| `UNIT_NPC_FLAG_VENDOR_AMMO` | `0x00000100` | 弹药 |
| `UNIT_NPC_FLAG_VENDOR_FOOD` | `0x00000200` | 食物 |
| `UNIT_NPC_FLAG_VENDOR_POISON` | `0x00000400` | 毒药 |
| `UNIT_NPC_FLAG_VENDOR_REAGENT` | `0x00000800` | 材料 |
| `UNIT_NPC_FLAG_REPAIR` | `0x00001000` | **修理** |

3. 官方挂件实测（本机 `acore_world`）：

| 挂件 NPC | entry | npcflag | 解码 | 侧 |
|----------|-------|---------|------|----|
| Hakmud of Argus「旅行商人」 | 32638 | 896 | VENDOR+AMMO+FOOD | 联盟 |
| Gnimo「冒险工匠」 | 32639 | 7296 | VENDOR+POISON+REAGENT+**REPAIR** | 联盟 |
| Mojodishu「旅行商人」 | 32642 | 896 | VENDOR+AMMO+FOOD | 部落 |
| Drix Blackwrench「修理工」 | 32641 | 7296 | VENDOR+POISON+REAGENT+**REPAIR** | 部落 |

> 官方苔原猛犸象模式 = 1 个杂货商 + 1 个材料商（兼修理）。

---

## 2. 前置条件

1. 坐骑已按多人骑乘文档配好载具：`creature_template.VehicleId` + `npc_spellclick_spells`（**必须先配 spellclick**，否则挂件加载报错跳过，`ObjectMgr.cpp` L4020–4035）。
2. 载具至少有 1 个乘客座位供商贩占用。
3. 词表候选坐骑：牦牛系 0350/0351/0420/0462、雷龙 0024/0466（`special_features` 含 `自带商人`/`修理`）。

---

## 3. 制作步骤

### 3.1 选商贩 NPC

**首选：直接复用官方挂件 NPC**（上表 4 个，货物清单 `npc_vendor` 已配好、对话文本齐全）。按坐骑阵营选对应侧的 NPC。

**次选：自建商贩**（想卖自定义货物时）：

```sql
-- 1. 建商贩 NPC（npcflag 按 §1 表组合）
INSERT INTO `creature_template` (`entry`, `name`, `npcflag`, `faction`, ...)
VALUES (<新entry>, '<商贩名>', <npcflag>, <阵营>, ...);

-- 2. 配货物
INSERT INTO `npc_vendor` (`entry`, `item`, `maxcount`, `incrtime`, `ExtendedCost`)
VALUES (<新entry>, <物品ID>, 0, 0, 0), ...;
```

- 只要修理功能：`npcflag = 0x1000`（REPAIR）；要卖东西再加 `0x80`（VENDOR）。
- 修理价格折扣与该 NPC 的 faction 声望挂钩（声望越高折扣越大），选阵营时留意。

### 3.2 挂商贩

```sql
INSERT INTO `vehicle_template_accessory`
  (`entry`, `accessory_entry`, `seat_id`, `minion`, `summontype`, `summontimer`)
VALUES
  (<坐骑生物 entry>, <商贩NPC entry>, 1, 0, 6, 30000),   -- 杂货商
  (<坐骑生物 entry>, <商贩NPC entry>, 2, 0, 6, 30000);   -- 材料/修理商（可选）
```

- `seat_id` = `Vehicle.dbc` 座位槽位下标（0 起）。
- `summontype=6`、`summontimer=30000` 沿用官方写法。

---

## 4. 注意事项

1. **商贩占用乘客座位**：玩家乘客要坐须先驱逐商贩（Eject）。「双人骑乘 + 商贩」合计需要至少 2 个座位（1 乘客 + 1 商贩）。
2. 其他玩家也能用你坐骑上的商贩（同官方猛犸象行为），属正常特性。
3. 货物清单改动只动 `npc_vendor` 表，无需重挂挂件。
4. 修理是服务端标准逻辑（按耐久度扣钱），无需额外配置。

---

## 5. 本项目落地差距

| 差距 | 现状 | 建议 |
|------|------|------|
| `vehicle_template_accessory` 无生成逻辑 | 无此表 SQL | 同多人骑乘文档 §7：YAML 增加 `vehicle_accessories` 字段后由管线生成 |
| 无前人验证 | 本项目首个商贩坐骑 | 上线后实测：购买、修理、驱逐后乘客入座 |
