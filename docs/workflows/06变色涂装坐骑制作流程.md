# 变色涂装坐骑（X-995 机械猫类）制作流程

本手册面向维护人员与 Agent，描述在 AzerothCore 3.3.5a 上把坐骑做成「变色涂装」（官方 X-995 型机械猫：可选多种涂装颜色）的回退实现流程。

> **定位**：BfA 的涂装选择机制 3.3.5 没有，回退方案 =「一个颜色 = 一只坐骑」+ 切换器。所有数值均核对自本地 `data/wow-dbc/src/dbc/`、AzerothCore 源码（`/Users/deadwalk/Code/azerothcore-wotlk/`）与本机 `acore_world` 数据库，非臆测。

---

## 1. 原理：3.3.5 的坐骑颜色由谁决定

调用链（`SpellAuraEffects.cpp` `HandleAuraMounted` L3361–3407）：

```text
坐骑法术 EffectMiscValue_1 → creature_template.entry
    → ObjectMgr::ChooseDisplayId(creatureInfo)（取 modelid1..4）
    → creature_display_info 记录 → ModelID（M2 模型）+ TextureVariation_1/2/3（贴图变体）
```

`CreatureDisplayInfo.dbc` 实测为 16 字段（64 字节/条），其中字段 6/7/8 = `TextureVariation_1/2/3`（字符串引用，贴图文件名不带扩展名）。**同一只 M2 模型，换 TextureVariation 即可换涂装**——这就是变色的实现点。

> 本项目坐骑 YAML 已维护 `texture_variations`（贴图变体名），新 display 记录直接引用对应变体名即可。

---

## 2. 前置条件

1. 原坐骑的 M2 模型自带多个贴图变体（.blp 文件在模型文件夹内，本项目资源库已按变体组织）。
2. 词表候选坐骑：0275 X-995 型机械猫（`special_features=变色涂装`）。

---

## 3. 制作步骤（每加一个颜色走一遍）

### 3.1 `CreatureDisplayInfo.dbc` 新增记录

| 字段 | 值 |
|------|-----|
| `ID` | 新分配（现有 24395 条，避开冲突） |
| `ModelID` | 与原坐骑相同（指向同一 `CreatureModelData` 记录） |
| `CreatureModelScale` | 与原坐骑相同（float，1.0 = 1065353216） |
| `TextureVariation_1` | 涂装贴图变体名（如 `mechanicaltiger_blue`） |
| 其余 | 参照原坐骑的 display 记录复制 |

### 3.2 `creature_template` 新增条目

复制原坐骑生物条目，仅改：

```sql
-- 示例：原坐骑 entry = X，新颜色 entry = X+90000（按项目 entry 分配规则）
INSERT INTO `creature_template` (...) SELECT ... FROM `creature_template` WHERE `entry` = X;
UPDATE `creature_template` SET `entry` = <新entry>, `modelid1` = <3.1的新displayID>, `name` = '<原坐骑名·涂装名>' WHERE `entry` = <新entry>;
```

### 3.3 `Spell.dbc` 新增坐骑法术

复制原坐骑法术记录，仅改：

| 字段 | 值 |
|------|-----|
| `ID` | 新法术 ID（项目分配段） |
| `Name_Lang` | `<原坐骑名（涂装名）>` |
| `EffectMiscValue_1` | 3.2 的新 creature entry |

### 3.4 切换器（换色入口）

3.3.5 无官方涂装 UI，用以下任一方式实现「换色」：

| 方式 | 实现 | 适用 |
|------|------|------|
| NPC 对话换色 | Eluna/SmartAI gossip：选项 → `Player::RemoveSpell(旧坐骑法术)` + `Player::LearnSpell(新坐骑法术)` | 推荐，体验最接近官方 |
| 使用物品换色 | 物品 spell 触发脚本，循环切换各颜色法术 | 无 NPC 场景 |

---

## 4. 注意事项

1. **每个颜色都是独立坐骑法术**：坐骑手册里会列出多只「同模型不同色」的坐骑，无法合并显示；这是 3.3.5 回退方案的固有限制。
2. `TextureVariation` 填的贴图名必须存在于该模型的文件夹内（本项目 `sources/` 对应模型目录），否则客户端显示为绿/蓝缺失贴图。
3. 新增 display 记录属于 `CreatureDisplayInfo.dbc`，**已在导出管线范围内**（`mount_patch_builder.py` L42–46 的 `REQUIRED_DBC_FILES` 含 CreatureDisplayInfo），管线扩展量小。
4. 换色后已召唤的坐骑不变（光环按施放时的法术解析），重新上马即新颜色。

---

## 5. 本项目落地差距

| 差距 | 现状 | 建议 |
|------|------|------|
| 管线不支持「同模型多 display」 | 当前一个坐骑 = 一个 display | YAML 增加 `color_variants`（变体名列表），导出时生成多 display + 多 creature + 多法术 |
| 无换色切换器 | 无 NPC/物品脚本 | Eluna 脚本实现，配置化（坐骑组 → 法术列表） |
| 无前人验证 | 本项目首个变色坐骑 | 首只上线后实测各涂装渲染与切换 |
