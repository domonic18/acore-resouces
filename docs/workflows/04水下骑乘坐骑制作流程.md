# 水下骑乘坐骑（海馬类）制作流程

本手册面向维护人员与 Agent，描述在 AzerothCore 3.3.5a 上把坐骑做成「水下骑乘」（瓦丝琪尔海马类）的完整流程、字段填写与注意事项。

> **定位**：水下骑乘本体纯客户端 DBC 可实现；「仅水下可用」的限制需脚本。所有数值均核对自本地 `data/wow-dbc/src/dbc/`、AzerothCore 源码（`/Users/deadwalk/Code/azerothcore-wotlk/`）与本机 `acore_world` 数据库，非臆测。

---

## 1. 原理

1. **服务端不禁止地面坐骑在水中施放**：`Spell.cpp` L6658–6662 只拦「带飞行速度光环（207）的坐骑」在水中使用（`IsInWater() && HasAura(MOD_INCREASE_MOUNTED_FLIGHT_SPEED)` → `SPELL_FAILED_ONLY_ABOVEWATER`），纯地面光环（78+32）的坐骑在水中放行。AC 是事后为飞行坐骑补的这个检查，反证客户端本身不硬拦游泳时施放坐骑法术。
2. **水下速度要单独给**：坐骑的地面速度光环 32（`MOD_INCREASE_MOUNTED_SPEED`）不作用于游泳；游泳加速用 `SPELL_AURA_MOD_INCREASE_SWIM_SPEED = 58`（`SpellAuraDefines.h` L121，处理器 `SpellAuraEffects.cpp` L3873，`UpdateSpeed(MOVE_SWIM)`）。
3. 可选叠加 `SPELL_AURA_WATER_BREATHING = 82`（L145）实现水下呼吸。
4. 官方参照：`7840`（Swim Speed Potion）实测 `EffectAura_1=58`、`EffectBasePoints_1=99`（→+100% 游泳速度；本项目惯例 BasePoints = 百分比 − 1，如坐骑地面 100% 速度存 99）。

---

## 2. 前置条件

1. 坐骑法术为**地面型**（无 207 飞行光环），否则水中直接被服务端拒绝。
2. 词表候选坐骑：0363/0364 瓦丝琪尔海马（`special_features=水下骑乘`）。

---

## 3. 制作步骤：坐骑法术加游泳速度效果

只改 `Spell.dbc` 该坐骑法术记录的第三效果组：

| 字段 | 值 | 说明 |
|------|-----|------|
| `Effect_3` | `6` | SPELL_EFFECT_APPLY_AURA |
| `ImplicitTargetA_3` | `1` | TARGET_UNIT_CASTER |
| `EffectAura_3` | `58` | SPELL_AURA_MOD_INCREASE_SWIM_SPEED |
| `EffectBasePoints_3` | `59` 或 `99` | +60% / +100% 游泳速度（百分比 − 1） |
| `EffectMiscValue_3` | `0` | 无需 |

可选：若还要水下呼吸，而效果位不够（地面型已用 2 个），则去掉水面用不到的效果或接受只加速不呼吸（玩家可自备水下呼吸药水/buff）。

### 「仅水下可用」限制（可选，需脚本）

3.3.5 **没有内建机制**：`SPELL_FAILED_ONLY_UNDERWATER = 96` 枚举存在（`SharedDefines.h` L1033）但全代码库无任何引用。若要海马只能水下召唤：

- 用 Eluna / 核心脚本挂施法事件，检查玩家 `IsUnderwater()`，不满足则取消并报错；
- 或接受「水陆两栖」（与地面坐骑重叠，通常不推荐，避免挤压普通坐骑价值）。

---

## 4. 注意事项

1. **客户端行为需实测**：按源码推断 3.3.5 客户端允许游泳时施放地面坐骑法术（否则 AC 无需为飞行坐骑补服务端检查），但首只海马上线前必须在游戏内实测「水中按坐骑键」。
2. 水下骑乘时地面速度光环 32 仍在效果位上但不起作用，属正常。
3. 坐骑在水中施放后，游出水面到陆地时 32 号地面速度恢复生效，无需特殊处理。
4. 若做飞行 + 水下双形态坐骑：飞行光环在水中施放被服务端拒绝，不要在同一法术里混用 207 与水下定位。

---

## 5. 本项目落地差距

| 差距 | 现状 | 建议 |
|------|------|------|
| 导出管线不支持第三效果 | `patch_exporter.py` 坐骑法术模板只写 `Effect_1/2`（L43–56） | YAML `special_features` 含 `水下骑乘` 时追加第三效果（6/1/58/速度值） |
| 无「仅水下」限制机制 | 服务端无代码路径 | 需要时 Eluna 脚本实现 |
| 无前人验证 | 本项目首个水下坐骑 | 首只上线后实测水中召唤与速度 |
