# 骑乘采集坐骑（飞天魔像类）制作流程

本手册面向维护人员与 Agent，描述在 AzerothCore 3.3.5a 上把坐骑做成「骑乘采集」（官方飞天魔像：骑乘状态可采药）的完整流程、字段填写与注意事项。

> **定位**：剥皮纯客户端 DBC 可实现；采药/采矿必须核心小补丁。所有数值均核对自本地 `data/wow-dbc/src/dbc/`、AzerothCore 源码（`/Users/deadwalk/Code/azerothcore-wotlk/`）与本机 `acore_world` 数据库，非臆测。

---

## 1. 原理：采集的两条路径在 3.3.5 完全不同

| 采集方式 | 实现形式 | 骑乘障碍 | 解法 |
|---------|---------|---------|------|
| **剥皮** | 法术（`SPELL_EFFECT_SKINNING = 95`，`SharedDefines.h` L861） | `Spell.cpp` L5988：骑乘施法且无 `SPELL_ATTR0_ALLOW_WHILE_MOUNTED` → `SPELL_FAILED_NOT_MOUNTED` | ✅ DBC 加属性即可 |
| **采药 / 采矿** | GameObject 使用（草药/矿点为 `GAMEOBJECT_TYPE_CHEST = 3`，实测 1617 银叶草、1618 宁神花、3725） | `GameObject.cpp` L1491：使用非 `IsUsableMounted()` 的 GO 时强制下马；`IsUsableMounted()` 仅认 QUESTGIVER/TEXT/GOOBER/SPELLCASTER 四种类型（`GameObjectData.h` L411），CHEST 不在列 | ❌ 必须核心补丁 |

> 官方飞天魔像的卖点是「骑乘采药」，因此在 3.3.5 复刻它绕不开核心补丁。

---

## 2. 前置条件

1. 坐骑本身已可用（标准坐骑法术 + creature_template）。
2. 坐骑光环 `AuraInterruptFlags=0`（本项目坐骑法术现状，实测 61425）——施放采集法术/使用 GO 不会从「打断」路径掉坐骑，障碍只有上表两处主动下马逻辑。
3. 词表候选坐骑：0379 飞天魔像（`special_features=骑乘采集`）。

---

## 3. 制作步骤

### 3.1 剥皮（纯 DBC）

给全部 9 个剥皮法术的 `Attributes` 加 `SPELL_ATTR0_ALLOW_WHILE_MOUNTED = 0x01000000`（`SharedDefines.h` L394）。

本地 `Spell.dbc` 实测带 SKINNING 效果（Effect=95）的法术全集：

```text
8613, 8617, 8618, 10768, 32605, 32606, 32678, 49383, 50305
```

示例（8613，现 `Attributes=0x10`）：

```text
Attributes: 0x10 → 0x01000010
```

> 客户端按已学最高等级施放对应 rank，故 9 个 rank 全改，漏一个则该 rank 不能骑乘剥皮。

### 3.2 采药 / 采矿（核心补丁）

在 `GameObject.cpp` L1491 一带的强制下马处放行「持有采集坐骑光环的玩家」：

```cpp
// 修改前
if (user->IsPlayer() && GetGoType() != GAMEOBJECT_TYPE_TRAP) // workaround for GO casting
    if (!m_goInfo->IsUsableMounted())
        user->RemoveAurasByType(SPELL_AURA_MOUNTED);

// 修改后：骑乘采集坐骑（持有指定坐骑光环）使用 GO 时不被下马
if (user->IsPlayer() && GetGoType() != GAMEOBJECT_TYPE_TRAP)
    if (!m_goInfo->IsUsableMounted() && !user->HasAura(GATHER_MOUNT_SPELL_ID))
        user->RemoveAurasByType(SPELL_AURA_MOUNTED);
```

- `GATHER_MOUNT_SPELL_ID` = 采集坐骑（如 0379 飞天魔像）的坐骑法术 ID，定义为常量。
- 若不想「开箱也不下马」，可在条件里再按 GO 类型/锁定技能过滤（`GetGOInfo()->type == GAMEOBJECT_TYPE_CHEST` 且 chest 锁类型为采集类）。

---

## 4. 注意事项

1. **范围控制**：§3.1 的属性是全局效果（所有坐骑都能骑乘剥皮）；§3.2 补丁若按坐骑光环判断则只放行指定坐骑。官方语义（仅采集坐骑受益）只能靠 §3.2 的光环判断方式达成；纯 DBC 的剥皮方案无法限定坐骑。
2. **战斗法术不受影响**：其他法术骑乘施放仍被 `Spell.cpp` L5988 拒绝（`SPELL_FAILED_NOT_MOUNTED`），不会破坏平衡。
3. Eluna 钩子无法阻止 L1491 的下马（钩子在下马之后触发），必须改 C++。
4. 采集动作本身有施法条/读条（剥皮 2 秒），骑乘读条期间可被攻击打断，属正常。

## 5. 本项目落地差距

| 差距 | 现状 | 建议 |
|------|------|------|
| 剥皮属性批量改写无管线支持 | wow-dbc-tool 可改单条 | 管线加「采集坐骑」规则：导出时改写 9 个剥皮法术 Attributes |
| 采药/采矿需核心补丁 | 服务端为纯 AC | 补丁放服务端自定义补丁集，常量集中定义 |
| 无前人验证 | 本项目首个采集坐骑 | 补丁上线后实测骑乘采药/剥皮/采矿 |
